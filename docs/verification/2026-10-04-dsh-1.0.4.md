# hello-cc 1.0.4 verification

The release retains the existing DeepSeek Harness integration and normal npm `latest` channel.

## Scope

Session display uses a bounded asynchronous batch of tmux observations. Cold, stale or failed data is unknown. Terminal control continues to use live observations and ownership checks. Runtime HTTP errors include the method, path without query, deadline and elapsed time; no broadcast retry is introduced. Already-cancelled requests do not open a transport.

The earlier 1.0.3 master macOS broadcast timeout remains recorded. A diagnostic local run of that exact release passed with 590 observed requests and a maximum session-list time of 901 ms. That success did not prove a root-cause fix. Version 1.0.4 removes an independently confirmed blocking path and improves future diagnosis; it does not assert the historical timeout's specific cause.
