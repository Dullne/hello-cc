## Scope

Session display uses a bounded asynchronous batch of tmux observations. Cold, stale or failed data is unknown. Terminal control continues to use live observations and ownership checks. Runtime HTTP errors include the method, path without query, deadline and elapsed time; no broadcast retry is introduced. Already-cancelled requests do not open a transport.

The earlier 1.0.3 master macOS broadcast timeout remains recorded. A diagnostic local run of that exact release passed with 590 observed requests and a maximum session-list time of 901 ms. That success did not prove a root-cause fix. Version 1.0.4 removes an independently confirmed blocking path and improves future diagnosis; it does not assert the historical timeout's specific cause.

## Fixture shutdown follow-up

The unpublished 010eaf7 candidate passed local checks, Linux CI and both installed-Harness CI jobs, but macOS regression timed out waiting for runtime exit. Its package and failure receipts remain archived. The regression fixture now records the exact process owner, refuses to signal reused or unknown PIDs, recognizes a zombie as exited, retains its original time budget and records bounded redacted failure context before cleanup. Eight targeted checks cover these semantics, including local-only lookup and structured diagnostics without message content. A failed CLI stop or fallback signal is still a failure. These changes improve fixture correctness and diagnosis without claiming the historical CI failure was conclusively attributed.

## macOS process liveness repair

An owned child independently reproduced a production defect: after exit, ps reported Z while process inspection and the exit waiter still reported live. Darwin inspection now includes process status in its existing before/after start-time reads and treats Z as dead. It preserves documented status modifiers (including traced processes), start identity, locale normalization and unknown handling. Mocked transitions and an owned real zombie exercise the repair; the parent reaps the fixture child. This proves the liveness defect and its repair, without attributing the earlier remote CI failure to it.
