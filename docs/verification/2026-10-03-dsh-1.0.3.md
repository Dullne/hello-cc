# DeepSeek Harness 1.0.3 verification

The original 1.0.2 diagnostic and package records remain historical evidence.
This release restores the complete later test set and repairs all 35 reported
failures, plus the additional state-permission, message-origin and native-owner
lifecycle gaps exposed by running the restored suite.

Local Node 24 / macOS validation: 918 unit tests, 917 passed, one Linux-specific
skip, zero failures; 63 factory modules audited; 13/13 integration stages passed.
The frozen npm artifact passed all eight official Harness 0.2.0-rc.2 installed
lifecycle checks. See `dsh-1.0.3-verification.json` for the 35-case mapping and
`dsh-1.0.3-package.json` for all 217 file hashes and the tarball digest.

CI must verify the manifest for its exact package version, including the entire
tarball digest, on both Linux and macOS. Registry publication, mainline commit,
current-device activation and real-model work have separate delivery receipts;
local tests do not establish those outcomes. This version uses npm `latest`.

The final DSH recovery implementation is preserved. Native ownership rejects
silent/legacy listeners conservatively; tests choose private roots with available
ports, without stopping other applications or relaxing product ownership checks.
