# Web 控制台展示与偏好优化方案

## 目标与范围

优化已有 hello-cc Web 控制台及登录页。保持现有项目、会话、协作操作、API v2、认证与终端数据协议；本次仅改展示、浏览器偏好和操作可达性。偏好属于当前浏览器，不写入服务器、项目或用户命令。

现状问题：语言入口随左侧栏折叠消失；登录页只有英文；深色配色固定且分散；字号偏小；三栏布局存在 640px 最小宽度；终端固定 13px/60 列导致窄屏显示不匹配；部分操作结果仍使用英文；弹窗、会话卡片和分隔条缺少完整键盘操作。

## 交互与配置

| 设置 | 选项与默认 | 即时行为 |
| --- | --- | --- |
| 语言 | 跟随系统、中文、English；默认跟随系统 | 更新所有界面文案、时间格式和无障碍标签，保留命令、项目路径、ID、用户消息及终端原文 |
| 界面主题 | 跟随系统、浅色、深色；默认跟随系统 | 更新背景、边框、文字、按钮、表单、弹窗和状态颜色；系统主题变化自动生效 |
| 终端主题 | 跟随界面、浅色、深色；默认跟随界面 | 使用 xterm 配色选项更新现有终端，不重建终端或连接 |
| 界面密度 | 舒适、紧凑；默认舒适 | 调整控件、卡片留白和辅助字号 |
| 终端字号 | 12、13、14、15、16、18、20px；默认 14px | 实际测量并调整行列，发送已有 resize 消息，不清空输出 |
| 专注模式 | 一键进入/退出 | 临时隐藏两侧栏；退出后恢复已保存的宽度与折叠状态 |

全局顶部固定提供设置、专注模式、连接状态与退出登录。设置使用弹窗，包含明确标签、当前值及关闭按钮；Esc 关闭、焦点限制在弹窗内、关闭后回到触发按钮。登录页共享语言和界面主题，错误与加载状态随语言切换。

宽屏保留可拖动三栏；窄于 1100px 时改为“会话 / 终端 / 项目状态”导航，一次展示一栏，设置入口始终可达。会话选中后进入终端。移动布局不覆盖桌面宽度偏好；返回宽屏恢复。分隔条支持方向键调整宽度，会话卡片支持 Enter/Space。

## 实现设计

1. 抽出双语词典，保留已有键，补齐设置、登录、操作结果及错误提示。产品名称、CLI 命令和用户内容保持原文。
2. 抽出共享偏好模块，提供校验、存储、系统偏好解析、主题变量、文案更新和控件绑定。沿用 `hcc.lang`；新增 `hcc.theme`、`hcc.density`、`hcc.terminalTheme`、`hcc.fontSize`。已有 en/zh 选择继续有效。损坏值回退默认；存储被禁用时在内存正常工作。
3. 在带 CSP nonce 的 head 脚本中先应用偏好，减少主题闪烁。所有内联脚本继续受现有 CSP 保护。深浅主题共用语义颜色变量，状态同时提供文本，键盘焦点清晰可见。
4. 控制台共享顶部与设置弹窗；用已缓存的数据重新渲染语言，保留消息草稿、活动会话、终端缓冲区与 WebSocket。定时刷新保留卡片键盘焦点。
5. 终端更新使用现有 xterm 实例，并通过真实单元格测量/fit 调整行列；只有可见且尺寸有效时 resize，避免移动页签隐藏状态产生错误尺寸。
6. 登录模板独立复用偏好，保留 POST /login 和成功跳转；补充提交中、认证失败与网络失败状态，不保存 token。

## 实施顺序

第一步：保存本方案、建立共享偏好和词典。第二步：接入主题、设置、密度与登录页。第三步：完成专注模式、移动导航、终端尺寸和键盘交互。第四步：补齐动态结果翻译，校验现有静态回归断言并运行检查。第五步：真实浏览器验证并修复发现的问题。

## 验收与风险

| 验收场景 | 通过标准 |
| --- | --- |
| 首次访问与刷新 | 系统语言/主题正确；手动选择刷新后保持；错误存储不阻断页面 |
| 桌面主题与语言切换 | 控制台、设置、动态卡片、结果和登录页一致，无残留固定深色块或缺失文案 |
| 活动终端切换设置 | 会话 ID、WebSocket 与输出保持，切换后仍能输入并收到真实 shell 输出；字号与列数匹配 |
| 1440/1024/390px | 无页面横向溢出；导航、设置、启动、终端及状态可用 |
| 专注与侧栏 | 临时隐藏，退出恢复宽度和折叠状态，刷新不误覆盖桌面设置 |
| 键盘与弹窗 | Tab 可达、焦点可见、Enter/Space 激活卡片、方向键调宽、Esc 关闭并恢复焦点 |
| 登录错误 | 空值有原生校验；无效 token 与网络失败显示本地化反馈；提交中避免重复请求 |
| 回归 | 自由标识符审计、单元测试、完整回归通过；每个内联脚本 nonce 有效且可解析；浏览器无未处理 JS 异常 |

重点风险是终端尺寸变化影响 TUI 排版、语言刷新影响草稿/焦点，以及窄屏隐藏面板时错误 resize。通过保留实例、可见性检查、缓存重渲染和真实交互验证控制风险。纯用户输出、未知后端错误细节与第三方 provider 文案保留原文，界面为其提供本地化说明。验证使用独立临时 HOME/项目/runtime，不修改已有项目数据或停止用户进程。当前环境未提供 Browser 插件，使用 Playwright 进行浏览器验收；截图与临时启动工具保存在仓库外。
