01 /

一个界面，管理多个 Agent

新建 Claude、Codex 或 DeepSeek Harness 后台 worker，查看结构化对话、工具执行、投递回执与审批。

02 /

共享上下文，明确分工

任务板、消息、事件与交接留在同一项目里。用显式团队计划拆分并行任务，用 advisory lock 协调编辑。

03 /

浏览器与终端，接着做

在 Web 接入 HCC 持有的后台 worker 或受管 tmux 终端，继续同一执行器，也保留本地 CLI 工作方式。

04 /

项目文件，随手可达

预览文本、Markdown、HTML、图片与 PDF；按需上传文件、编辑文本，保存项目启动默认值并切换项目。

协作锁用于约定编辑范围；桌面 App 保留自己的执行器，通过各自的接入方式参与协作。了解使用边界 ↗
